# GitHub & PDF Assistant

🚧 Status: Work in Progress

This project is an AI-powered assistant that can answer questions from GitHub repositories and PDF documents using Retrieval-Augmented Generation (RAG).

## Implemented
- Clone GitHub repositories
- Validate GitHub URLs
- Basic project structure
- Repository file access

## Planned
- Parse repository files
- Build vector database
- PDF ingestion
- RAG question answering
- Streamlit interface
